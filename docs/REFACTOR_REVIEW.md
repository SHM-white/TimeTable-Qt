回归：Linux 课程模型测试、明暗主题 offscreen 启动测试、逐页切换确认没有残余 QGraphicsEffect 的 UI smoke、Windows MSVC 构建及 Qt Runtime 部署。**自动化只能排除崩溃和编译失败，实际 Windows UI 渲染仍需操作验证。**

# TimeTable-Qt 老项目审查与新版工作计划

## 旧项目主要问题

| 发现 | 影响 | 新版处理 |
|---|---|---|
| 全局 `include.h` 同时引入 Windows.h、Qt、jsoncpp、libhv、宏定义 | 耦合严重，无法单测/跨平台 | 新模型仅依赖 QtCore |
| `Lesson` 只包含星期、课名、HHMM 起止时间 | 不支持教学周和单双周 | 课程储存显式有效周列表 |
| `Settings_New` 与 `MainWindow` 直接操作底层数据和窗口 | UI/业务逻辑混杂 | UI 调用 ScheduleStore 服务 |
| 配置与图片副本、历史工程文件、预编译库 | 工程维护负担高 | CMake 新工程无预编译第三方依赖 |
| config.json 带有旧开发机的 D:/ 路径 | 迁移安装路径会失效 | 用户 AppData 路径与用户可导出数据 |
| Actions checkout@v2、upload-artifact@v2、Qt5/Qt6 混合编译 | 旧工作流可能不再运行 | CMake + Windows 自动打包 + Linux 测试 |

## 已提交实现

- 纯 QtCore 排课引擎、课表 JSON Schema、原子存储。
- 学期日期/周数、单双周/指定周解析、休息日/补课映射、今明课程查询。
- 七日周视图、今日课程倒计时与进度、课程配置与管理、深浅主题、淡入切换与托盘。
- CSV、ICS、旧版 JSON 与小爱 courseInfos 离线格式兼容。
- 课程逻辑回归测试、Windows 便携包 CI、Linux 编译测试。
