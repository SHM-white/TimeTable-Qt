# TimeTable Next · 桌面课表与信息卡片

当前版本 4.2.0，更新于 2026-10-11。新版工程位于 `modern/`，旧版源码保留在 `TimeTable-Qt/`。功能覆盖及尚存差异见 [旧版功能迁移审计](docs/LEGACY_FEATURE_AUDIT.md)；历史阶段文档不代表当前实现。

## 桌面卡片

首次启动显示时间、当前课程、下一节课程三张紧凑卡片。拖动空白处移动，拖右下角缩放，右键可以折叠/展开、置顶、锁定、编辑或打开完整课表。折叠与展开分别记住尺寸。打开课程管理器或桌面窗口管理页时，卡片会暂时隐藏，关闭后恢复。

右键 → **管理全部桌面窗口**，可以新建、删除、编辑窗口，设置 **启动显示 / 隐藏**。**全部显示、全部隐藏及右键隐藏窗口只影响本次运行**，不会更改下次启动偏好。Windows 开机自启动使用当前用户的 HKCU Run 设置，不需要管理员权限。

右键 → **设置此窗口**，可以设置标题、主题、背景颜色/图片、透明度、文字大小、边距、圆角、FPS、调试边框、实时绘制 FPS 和可选亚克力效果。FPS 范围为 0–120；0 停止连续滚动动画，课程/时钟数据更新和轮播切换仍继续。FPS 显示的是实际重绘频率，静态或隐藏窗口不会为达到设置值持续重绘。亚克力通过 Windows 接口尝试启用，不支持时保留普通透明背景；效果仍需 Windows 实机验收。

正式桌面和编辑器预览共用元素渲染器。长文本位置由单调时钟计算，动画帧与每秒数据刷新分开；仅可见且文字溢出的窗口启用连续动画，背景图片缓存后绘制。

## 自由元素编辑器

右键卡片 → **编辑自由元素布局**，或在窗口设置的“显示内容”中打开编辑器。

- 支持时间、当前/下一节课、下节倒计时、目标日倒计时、每日信息、今日课表、教学周、文字进度、图形进度条、指针时钟、天气文字/天气块、新闻、每日一句和便签。
- 元素可设坐标、宽高及按内容自动计算尺寸；每个条目可设模板、字体、字号、RGBA 文字颜色和粗体。今日课表支持完整名称/首字、普通排布/竖排文字及当前课程高亮。
- 组合模式支持单项、轮播、同时显示；同时显示可纵向、横向或网格排布。轮播可固定停留时间，也可选 **长文字滚完再切换**；滚动速度以 px/s 设置。**每日信息逐条轮换**每 5 秒显示当天一条消息，也可关闭后合并显示。
- Ctrl 点击或拖动空白处框选多个元素；组合后一起选择和移动。支持网格吸附、元素边缘/中心吸附、六种对齐方式、撤销及重做。Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做，Ctrl+G 组合，Ctrl+Shift+G 解组。
- 点击“保存布局”提交，取消会保留原布局。窗口设置中的“根据元素占用空间自动调整展开尺寸”与元素自身的自动尺寸可以配合使用，今日课表随内容变化重新计算。

时钟模板支持 C `strftime` 格式（例如 `%H:%M:%S`），普通数据模板支持 `{value}`。倒计时支持按天/时/分/秒顺序填入的 `%d`、`%03d` 等整数占位符；不执行任意 printf 格式串。

## 课表、导入和学期档案

完整课程管理器支持教学周、单双周、指定周、课程增删改复制、教师/地点/配色、节次时间表、七日周视图、当天进度与倒计时。特殊日期可以设为整日休息，或改按另一日期上课，教学周规则随来源日期计算。

“课程”页可按课程、教师、地点、星期、教学周或时间搜索，空格分隔的条件需同时匹配。**检查冲突**报告星期、上课时间和教学周均重叠的课程；报告不会禁止保存合理重叠。

侧栏 **导入数据** 支持新版 JSON、旧版 Lessons.json、UTF-8 CSV 和小爱 `courseInfos` JSON，可选择：

- **追加合并**：保留已有课程、每日 Infos 和调休，按课程内容去重，并避免 ID 碰撞；同日期的调休以现有安排为准。
- **替换当前课表**：校验并成功写入后替换。建议事先导出备份。

原生 JSON 的开学日期与当前课表不同时，追加会拒绝合并，避免周数错位；请替换或切换学期档案。导入失败不会修改当前模型或源文件。导出支持新版 JSON、CSV、ICS 日历和小爱结构 JSON。

设置 → **课表文件与学期档案**：

1. **选择课表文件**把有效的新版 JSON 设为持续读写的活动课表；先完整校验，失败或取消会保留当前课表与路径。
2. **课表另存为**原子保存当前数据并切换到新文件；**恢复默认课表**回到默认路径。
3. **命名当前档案**为当前路径命名，再通过下拉列表和“切换学期”在多个独立课表间切换。移除档案记录不会删除文件。
4. **将导入文件转换为独立 JSON**转换 CSV/旧版 JSON/小爱结构，不改变活动课表。没有学期信息的源文件使用当前学期和节次设置，转换前请先核对这些设置。

设置 → **课程提醒**默认关闭，可以选择提前 0–1440 分钟。启用后按实际课程日期及调休发送一次托盘通知，无托盘时使用状态栏提示；0 表示上课时提醒。提醒标记持久保存，避免每秒或重启后重复通知。提醒需程序正在运行，短时错过会在 60 秒窗口内补发。

设置 → **界面语言**支持中文和 English，保存后重启生效；用户填写的课名、教师、地点和自定义文本保持原内容。

### CSV 示例

使用 UTF-8，可带 BOM，字段顺序为 `name,weekday,start,end,weeks,teacher,room`。支持标准 CSV 双引号、逗号、转义双引号及引号内换行。

```csv
name,weekday,start,end,weeks,teacher,room
离散数学,1,08:00,09:40,1-16单,王老师,教一 201
数据库,3,14:00,15:40,2-18双,李老师,机房 402
```

周一为 1，周日为 7。周数支持 `全部` / `All`、`1-16`、`1-16单` / `1-16odd`、`2-18双` / `2-18even`、`1-8,10,12`，以及独立的 `odd` / `even`。旧版 `Mon,课程名称,0800,0940` 也可导入。

小爱互通仅支持本地 `courseInfos` 数据结构（name、day、sections、weeks、teacher、position）；不是官方账户同步或通用手机导入协议。导入前核对节次映射。ICS 当前仅支持导出，时间为本地浮动时间，没有显式 TZID。

## 天气、新闻和每日一句

在元素编辑器选择对应内容类型后配置数据源。无配置时不会自动请求网络。

- **天气**：高德 Web 服务 API Key + 6 位 Adcode，或留空 Adcode，填写城市/识别地址自动地理编码。可选择实况或今日/明日预报。异步请求，成功天气缓存约一小时，失败重试并保留可用缓存。
- **新闻 / 每日一句**：填写 HTTPS RSS、Atom、JSON 地址，或选择 UTF-8 文本/RSS/JSON 本机文件；本机文件优先。纯文本每行一条，新闻每 15 秒轮换，每日一句按日期选择。联网源约 15 分钟更新一次，失败时保留缓存。未填写源时，可在“文本 / 格式”中使用固定内容，兼容旧版占位文字。

天气 Key 明文保存在本机布局数据中，布局备份也会包含该 Key；新闻/每日一句的本地源文件不会嵌入布局备份。联网实现已具备请求与缓存流程，当前自动测试使用离线响应样本，未验证真实 API Key、线上订阅站点及 Windows TLS 环境。

## 存储、备份和旧版迁移

默认课表为 `QStandardPaths::AppDataLocation/schedule.json`，默认布局为同目录的 `desktop-layout.json`，两者均可选择其他路径。路径、学期档案、提醒和界面偏好保存在当前用户 QSettings 中。

- **导出与备份**导出课表；桌面窗口管理页的 **备份完整布局 / 恢复完整布局**保存或恢复窗口、自由元素、样式、两套尺寸、启动偏好和内嵌背景图片。恢复前完整校验，再替换活动布局。
- **更改配置路径**可以读取已有有效布局，或把当前布局保存到新路径。旧预览版 QSettings 窗口数据会迁移到布局文件。
- **导入旧版窗口**读取旧 `config.json` 的 `MainWindow` 与 `Windows`，追加迁移窗口，不覆盖课表。保留元素几何、字体、颜色、模板、背景、旧 FPS/滚动速度、启动偏好和窗口参数；相对背景图依次尝试配置目录与程序目录。
- 旧 `Lessons.json` 需另走“导入数据”。目前没有自动追踪旧 `ConfigFile` / `LessonInfoFile` 的一步迁移向导，也没有把课表、布局、QSettings 偏好及外部内容源打成单个总备份。

课表或布局加载失败时，自动保存暂停，原始文件保留。课表内存修改可以导出或另存到新路径；明确导入有效课表可替换损坏文件。布局可通过恢复有效备份或更改路径继续使用。单纯修改外观不会解除损坏课表保护。

## 构建与 Windows 分发

需要 CMake 3.21+、C++17，以及 Qt Core/Widgets/Network。Qt6 为主版本，Qt5.15 为兼容构建；界面使用 Qt Widgets，不依赖 Windows App SDK。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Qt5 可加 `-DTIMETABLE_FORCE_QT5=ON`，并使用独立构建目录。Linux GUI 检查可设置 `QT_QPA_PLATFORM=offscreen`，运行 `build/bin/TimeTableNext --smoke-test-light`、`--smoke-test-dark`、`--smoke-navigation` 或 `--smoke-test-english`。

Windows 工作流配置 Qt6.8.3 / x64 主构建和 Qt5.15.2 / x64 Win7 兼容候选，分别运行 `windeployqt` 并生成便携 ZIP 和 Inno Setup 当前用户安装包。安装流程支持快捷方式、可选自启、升级和卸载保留用户数据；不会自动发布 Releases。具体 artifact 名称和本地打包方法见 [安装包说明](packaging/README.md)。是否已产生可下载包需核对对应 Windows CI 作业结果。

本轮 Linux Release 构建中，Qt5.15 和 Qt6 均通过全部 8 组回归（共 16/16）：课表、元素、桌面窗口、主窗口数据保护、内容源、编辑器、布局存储和翻译；两套构建的浅色、深色、页面切换及英文启动检查也全部通过（共 8/8）。真实 Windows 安装/升级/卸载、亚克力、多屏、高 DPI、托盘通知、自启与联网服务仍需实机验证；Linux 离屏测试不能证明这些桌面行为。
